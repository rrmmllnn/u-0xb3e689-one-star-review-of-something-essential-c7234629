Entry for the [One-Star Review of Something Essential](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629)
bounty on make.fun: the funniest deadpan one-star review, 160 characters
or fewer, of an everyday essential.

## The review

> The sun provides free light and warmth every day, then sunburns the one square inch of skin I forgot to cover.

One star. The sun's one daily service is free light and warmth — and its
one daily failure is finding the single patch of skin you missed.

## How it runs

`main.py` (Python 3, standard library only) writes the review to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing
newline, so the file holds exactly the review — 110 characters.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
